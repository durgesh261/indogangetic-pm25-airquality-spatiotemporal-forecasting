1. System Architecture Overview

VayuDrishti provides a full-stack atmospheric machine learning platform specifically engineered for the Indo-Gangetic Basin. The system architecture is composed of four modular subsystems:

  • Spatiotemporal Sensor Mesh: Ingests continuous ambient air quality readings from 15 CPCB monitoring stations across Delhi-NCR, Haryana, Punjab, and Uttar Pradesh.
  • Atmospheric Advection Graph: Models dynamic air mass movement using geographic distance decay combined with learnable multi-head spatial attention.
  • Multi-Horizon Quantile Decoder: Generates well-calibrated probabilistic forecast intervals [q10, q50, q90] across 24h, 48h, and 72h lead horizons.
  • Causal Stubble Attribution Engine: Evaluates counterfactual zero-burn scenarios to isolate upstream biomass combustion from urban vehicular and industrial baselines.

2. Mathematical Invariants & Verification

The core neural forecaster is trained using the Asymmetric Multi-Quantile Pinball loss function: 

# Multi-Quantile Pinball Loss in PyTorch
class MultiQuantileLoss(nn.Module):
    def __init__(self, quantiles=(0.10, 0.50, 0.90)):
        super().__init__()
        self.quantiles = quantiles

    def forward(self, preds, targets):
        # preds: [B, N, H, 3], targets: [B, N, H]
        losses = []
        for i, q in enumerate(self.quantiles):
            err = targets - preds[..., i]
            loss_q = torch.max(q * err, (q - 1.0) * err)
            losses.append(loss_q.mean())
        return torch.stack(losses).sum()

3. CPCB National Air Quality Index (NAQI) Standards

AQI Category PM2.5 Range (24h avg) Color Indicator Public Health Impact & Regulatory Action
Good 0 - 30 µg/m³ ● Emerald Green Minimal impact. Normal outdoor activity permitted.
Satisfactory 31 - 60 µg/m³ ● Lime Green Minor breathing discomfort to sensitive individuals.
Moderate 61 - 90 µg/m³ ● Amber Yellow Discomfort to people with asthma and heart diseases.
Poor 91 - 120 µg/m³ ● Bright Orange Breathing discomfort to most people on prolonged exposure.
Very Poor 121 - 250 µg/m³ ● Crimson Red Respiratory illness on prolonged exposure. GRAP Stage III.
Severe > 250 µg/m³ ● Purple / Maroon Affects healthy people; seriously impacts sick. GRAP Stage IV emergency.

4. REST API Specification

The platform includes a high-performance FastAPI service running at http://localhost:8000. Key endpoints include:

GET/health

Health status check and model availability.

GET/api/v1/stations

Retrieve list of all 15 CPCB stations, geographic coordinates, and Delhi-NCR region flags.

GET/api/v1/metrics

Fetch held-out test evaluation benchmarks, including 24h/48h/72h MAE, RMSE, and PICP coverage.

POST/api/v1/forecast

Generate multi-horizon quantile predictions for provided sensor feature tensors.

curl -X POST "http://localhost:8000/api/v1/forecast" \
  -H "Content-Type: application/json" \
  -d '{"station_id": 0, "features": [[280.5, 45.2, 14.1, 210.0, 2.8, 850.0]]}'
POST/api/v1/attribute

Perform counterfactual ablation on active satellite fire radiative power to return stubble vs urban attribution percentages.

GET/api/v1/episodes

List historical winter smog episodes and synthetic test scenarios for regional analysis.

5. Quickstart Guide

# 1. Clone repository
git clone https://github.com/durgesh261/indogangetic-pm25-airquality-spatiotemporal-forecasting.git
cd indogangetic-pm25-airquality-spatiotemporal-forecasting

# 2. Install dependencies
pip install -r requirements.txt

# 3. Train spatiotemporal model & run tests
python -m unittest discover tests/

# 4. Launch FastAPI server
uvicorn src.api:app --reload --port 8000
